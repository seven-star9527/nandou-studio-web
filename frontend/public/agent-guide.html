快捷修图

打开「图片创作 → 图片生成」，在输入框下方选择工具，点击上传或直接拖入原图。

  • 透明底抠图　自动识别主体，或在原图点选补留、移除的物件。处理后可在白底和深底间切换，检查边缘，必要时用「调整边缘」补留或擦除，再下载透明 PNG。需要成品底色时选择背景色并点「换纯色底」或「换影棚底」，可下载换底成图或点「返回透明底」继续修边。
  • 主图精修　默认自动识别，完成后可见识别类目。不确定时用通用商品处理。也可手选调色盘、画笔、颜料、水彩纸 / 本、微缩模型或玩具，手选优先。再选背景和曝光，处理后对照原图查看材质、颜色和印字。
  • 高清放大　选择 2×、4× 或「上限内放大」。默认「细节增强」用于恢复印字、轮廓和材质。希望尽量保留原有噪点、渐变或缩短等待，可选「保真放大」。在结果上点「查看 100%」检查细线和小字，再下载 PNG。输出上限为 6400 万像素。

在原图或结果上滚动缩放、拖动平移。可下载结果，也可将它加入画布与其他版本并排比较。

从模板到画布

图片创作的「我的配置」与「Agent 创作 → 生成偏好 → 我的配置」共用同一账号的 5 个配置位和一个默认配置。调好参数后命名并保存。点击配置名称可临时使用，点「设为默认」可更换默认。提交成功后，下次创作恢复默认。Agent 支持云模型配置，含自定义尺寸、GIF 帧参数或透明 SVG。本地 Qwen 配置仅图片创作可用。使用平台、用途和风格在 Agent 中单独设置。

在「图片创作」选择商品图、构图、YouTube 或 TikTok 封面。点一款模板查看样图，编辑提示词里的【商品】和【标题】，再决定如何使用。

套用模板

将编辑好的提示词和当前模型支持的画幅带入输入框。需要借用样图构图时勾选「套用时带入样图」。已有商品图会保留，可直接替换示例中的商品描述。核对模型、张数和积分后再点击生成。

仅用作参考图

只把当前预览加入参考图，继续使用你自己的提示词和画幅。样图中的包装或部件仅作构图参考，真实商品请附实拍。

  1. 选择「画布 → 新建画布」即可开始。首次点「保存项目」会选中默认名「未命名画布」，输入名称后按 Enter。位置、图层和视图会自动保存，下次从「我的画布」打开。
  2. 拖入图片或视频，或用左侧工具添加文本、生成图片。拖动空白处平移，滚轮缩放；「并排整理」适合比较多张商品图。点击重叠节点露出的部分即可置顶。拖视频画面移动节点，底部控制条可播放或拖动进度。右上角「图层」可选中、改名或控制显隐。
  3. 将指针移到节点边缘，点左侧或右侧「＋」，再选「文本」「图片」或「视频」。新节点立即与原节点连线。点空图片或视频节点上传素材，也可把文件直接拖入。点节点名称旁的标签可标色或清除。
  4. 选中文本框可更换背景色，双击可编辑。选中文字可加粗、倾斜、加下划线或删除线，也可设置标题、列表、引用和段落对齐。拖动文本框右下角调整大小，点空白处结束编辑。
  5. 点选图片，在图片上方点「智能改图」，也可直接抠图、主图精修、高清放大或下载。智能改图可选择画笔、颜料盒或玩具的精修提示，再按实拍内容修改，核对比例和费用后点「生成到当前画布」。生成进度显示在新图位置，出图后与原图连线。可返回项目列表，稍后重开查看结果。
  6. 选中图层按 Delete 移出画布，Ctrl / Cmd + Z 或「撤销」可恢复刚移出的图层。在文本框内可正常编辑文字。快捷修图完成后点「添加到当前画布」继续对比。

在图片创作或 Agent 创作的输入框里，点击参考图缩略图打开预览。切到想使用的图片，点「添加到画布」，即可把这张原图加入已有或新建的画布。

在左侧「创作记录」点作品缩略图，在图像详情点「原图与生成图一起对比」，选择已有画布或新建画布。全部参考原图按上传顺序从左到右排列，最右侧是当前查看的生成图。只需结果时点「添加到画布」。管理员查看其他账号的作品时，画布和修图结果保存在管理员自己的账号下。等待或失败的历史任务可展开「任务动态」查看。

处理真实商品主图

保留原图细节

在「主图精修」选商品类目、背景和曝光。纯白背景可勾选「主体居中放大」。水彩本可单独选择，保留纸张纹理。点「查看 100%」对比笔尖、色序、标签和接缝。需要去掉灰尘时，点「局部去瑕」，在瑕疵上滚动滚轮或按 ＋ / − 缩放，空格拖动或中键拖动平移，按 0 查看全图，再用略大于污点的画笔标记。应用后由 PhotoCraft 修复标记区域。

处理多件商品

套装、浅色盒盖和道具容易混在一起。先自动识别主体。需要保留其他物件时选「补留主体」，要去掉道具时选「移除主体」，在原图点它们的内部。切换这两个按钮会保留所有选点，点错可撤销，选好后一起处理。三个快捷工具都可在原图或结果上滚轮缩放、拖动平移。「查看 100%」按实际像素检查，点「适应窗口」返回全图。处理后切换深色和白色检查边缘，用「调整边缘」补回缺件或擦除道具，再点「用此蒙版精修」。检查白纸、浅色盒盖和镂空。浅色侧翼漏选时，先选「补留主体」，再点翼片中央；真实开孔应能透出检查底色。需要透明底时直接下载 PNG。要交付可返修的白底主图，在修图 Agent 上传一张实拍图，点击「技能 → 设计师白底精修」并发送。也可直接输入「画笔设计师白底精修」指定品类。下载 PNG 或 PhotoCraft 工程；点「实拍主体」的蒙版补白可恢复误删的原片边缘，涂黑可去掉多余背景。「材质与色温」可调不透明度，「明暗层次」可单独调整。工作流保持原构图，不自动添加画作或调整配件。已有透明图可保留其轮廓，但无法恢复上传前已经删除的图像内容。在修图 Agent 中可输入「画笔白底精修」「水彩本保留背景精修」，也可要求抠透明底并保留手与商品，或上传商品图并输入「制作横版封面，标题为“水彩练习”」。也可使用竖版、方形，生成后可下载工程单独编辑标题和商品图层。

智能改图 · 画笔布光示例以这张实拍为底，保持支数、笔尖轮廓、笔杆印字和相对位置。柔化金属接头的刺眼反光，保留笔毛层次与笔杆纹理，只清理背景浮尘。输出与原图相同画幅的商品主图。

生成式布光会重新描绘局部。将派生图和实拍并排检查，尤其留意笔锋、商标小字和零件数量。

做出第一张图

  1. 切换到「Agent 创作」。开启新创作，或从左侧「任务记录」按缩略图找到已有任务。
  2. 上传商品实拍，说清用途。真实商品优先带参考图。只想试创意时，可以直接说明“先做概念图”。
  3. 检查生成偏好，发送需求。需求明确就会开始；缺少必要信息时，Agent 会问你一个关键问题。
  4. 查看成图并反馈。点击图片放大，核对产品，再说出想修改的地方。
可以直接这样说 · 水彩画笔场景图请用我上传的这套三支水彩画笔，做一张独立站商品场景图。保留支数、笔头、黑色笔杆和银色接头，笔杆保持笔直。放在干净的浅色画室桌面，柔和侧窗光，左侧留出文案位置。商品全新，不添加文字，先出一张。

如果需要一套图，告诉它每张图的任务，例如白底主图、笔头细节、画室场景。一次最多 4 张，更多内容分批做更容易控制方向。没有明确要求多张时，默认先做 1 张。

让 Agent 看懂参考图

Agent 能实际查看你上传的图片。它可以观察外形、颜色、布局和可见文字，也能调用工具检查生成结果。图片里无法确定的材质、规格、适龄和认证，请用文字补充。

告诉它，每张图负责什么

“第一张是实际售卖的三支画笔，第二张只参考光线，不要带入第二张的商品和道具。”比单纯上传两张图片更明确。

重要细节，给一张近照

细小的笔尖、金属箍、包装文字容易在整图中被忽略。上传清楚的局部实拍，并说明要检查的位置。

每轮最多使用 8 张参考图。在输入框或参考图区域按 Ctrl + V 可粘贴图片，左右拖动缩略图时可预览新顺序，松开后生效。上传图片后，提示词内会出现带缩略图的文件名，可将它拖到句中，也可从参考图区再拖入一次。拖动时，竖线会显示引用的插入位置，松手即可放下。在提示词中输入 @ 可打开已添加的图片，按 ↑、↓ 选择，回车插入。更换图片顺序后，文字中的引用仍指向原图。悬停预览，点击放大。理解图片时会使用适配尺寸的预览；原有上传素材仍可用于后续编辑。预览不是逐像素质检，正式使用前仍需放大核对原图。

长对话不会把所有旧图片每轮重新发送。系统保留图片记录，需要时让 Agent 重看指定图片；可以点击成图下的「以此图继续修改」明确指定目标。若细节要求发生变化，建议同时附上原始商品实拍。

选择合适的技能

点击输入框工具栏的「技能」，会打开浮动列表。选中一个技能会将要求添加到草稿，不会立即生图；检查后再发送。也可以不选，让 Agent 按需求匹配。

商品摄影

白底主图、材质近照、干净棚拍。重点是支数、轮廓和实际售卖内容。

电商场景

画室桌面、家庭空间和产品使用场景。布景围绕商品，不抢主体。

A+ 与卖点图

拆分一组图片的任务、安排层级和文字空间。卖点以你提供的真实资料为准。

品牌海报

探索主题、配色与版式。请提供需要逐字保留的品牌名和文案。

参考图精修

保留商品，只修改背景、光线或指定区域。适合在选中版本上继续调整。

独立站横幅

安排横向构图、标题与按钮留白，并考虑移动端裁切。

商品默认全新、干净、完整。质感来自光线、材质与自然阴影；除非你明确要求，不会主动加入磨损、污渍或做旧。

设置画质与费用

需要矢量文件时，在图片创作的尺寸菜单选择「SVG 矢量图」，或在 Agent 中明确要求「导出 SVG」。两款 GPT Image 2.6 都支持每次生成一张，可带参考图。参考图转透明 SVG 时，在尺寸菜单勾选「指定透明背景」，或在 Agent 对话中写明「透明背景」。可以预览并下载 SVG 原件；图像与 gpt-5.4-mini 写作分别计费，部分按张计价的供应商账号不支持 SVG。

制作 GIF 时，在图片创作的尺寸菜单选择「GIF 动图」，设置单帧宽高、帧数和时长。也可以在 Agent 创作里直接描述动作，例如「让参考图中的纸灯笼轻轻摇摆，做成循环 GIF」。默认单帧 512 × 512、9 帧、每帧 200 毫秒，计费按整张帧拼图及输入用量结算。可在创作记录或 Agent 对话中播放、下载原动图。

默认使用 GPT Image 2.6 Flare · medium · 1K。先确定构图，再按需要提高规格。智能比例只负责选画面比例，不会自动提高画质、分辨率或模型档位。

  1. 比例：可让 Agent 按用途选择，也可固定为方形、横图或竖图。
  2. 模型：Flare 先试新画面，Sunburst 优先参考图编辑，Nano Banana 可尝试另一种风格。Agent 当前提供这三款云端模型；本地 Qwen 在图片创作中使用。
  3. 质量与分辨率：GPT 可选低、中、高、超高；不提供 max。Nano 没有单独的画质档位。1K、2K、4K 是档位，最终像素看原图详情。
  4. 数量：跟随需求时默认 1 张，也可固定 1–4 张作为本轮出图要求与上限。
  5. 创作方向：选择 Amazon 或独立站、图片用途和视觉风格，减少每次重复描述。

发送区显示每张图片的预估积分，实际任务也会展示费用。多张图、继续修改和提高规格都可能增加消耗。完整模型区别请看 模型怎么选 →。

看图、反馈、继续调整

你会看到简短创作方案、技能与工具的执行状态、生成图片，以及检查后的说明。长回复会逐步出现。Agent 检查结果后会等待反馈，不会因为自己觉得不满意就反复花积分重做。

反馈要具体 · 保留什么，只改什么保留第三张的商品位置、三支画笔和整体光线。只把背景改成更浅的暖灰色，左边多留一点空白，不改变笔杆形状，不增加配件。

正式使用前重点看：笔杆是否弯折、支数是否正确、笔头与接头是否自然、包装文字是否准确、玩具部件是否齐全、道具是否会被误解为随售配件。图片看起来合理，不等于商品参数已经得到验证。

满意后可以告诉 Agent“这一版完成”。需要另一种方向时继续描述，或开启新创作，避免把不同商品混在一个长对话里。

草稿、对话与记忆

草稿：切换回来还在

图片创作与 Agent 各自保留文字和参考图。Agent 的不同对话也各自保存草稿。草稿在当前浏览器，换设备或清理浏览器数据后不能保证找回。

对话：接着上次继续

已发送的对话保存在账号中，没有固定总轮数。记录变长时，会整理较早内容为会话摘要，原始记录保留；近期要求优先。

长期偏好：由你决定记住什么

打开生成偏好中的「我的长期偏好」，手动保存品牌风格、品类、语言或禁用元素。后续对话会参考，也可以清空。

当前要求：优先于旧偏好

偏好不是不可修改的规则。换品类、换语言或有特殊构图时，直接说清楚，并检查本次生成偏好。

摘要可能遗漏细节。对商品身份、必须保留的文字和关键禁改项，建议在开始新一轮重要修改时再次确认。你的作品和对话按账号隔离；从本人列表删除后，管理员仍可查看。

常见问题

为什么有时会停下来，让我继续？

每轮默认最多进行 10 次模型调用，这是一次发送内的执行上限，不是最多只能聊 10 轮。达到上限时已有结果保留，你可以发送下一步要求继续。超时、输出过长也会明确提示，不会自动重提交已付费的图片任务。

需求很长，会被偷偷截掉吗？

每条需求最多 8,000 个字符，长期偏好最多 4,000 个字符。建议把复杂任务按商品或批次拆开。较早对话会摘要化；请求超出安全容量时会提示分批处理，不会悄悄裁掉要求后继续生图。输出达到上限时，当前文字可能不完整，未完整返回的工具指令不会执行。

图片很多，会把对话空间占满吗？

图片用图像格式输入，不把图片编码当成长篇文字。系统去除重复视觉输入，并限制一次携带的历史预览数量；旧图片仍保留，可按需重看。商品识别不确定时，请补充清晰近照，不要仅依靠反复增加相似图片。

生成很久或断线了，要重新发送吗？

先查看当前对话和创作记录。图片供应商可能仍在处理，刷新会核对原任务。停止 Agent 只停止后续操作，已经提交的图片仍可能完成并计费。不要把重新发起相同生图需求当作刷新。

设置窗口怎么关闭？

点击窗口外的空白处、按 Esc，或点击关闭按钮。技能和生成偏好以浮动面板打开，不会挤开输入框。
