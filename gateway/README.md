# 账号网关与创作 Agent

## 修图 Agent

Agent 创作输入框左侧可选择“生图 Agent / 修图 Agent”。两个智能体共享创意空间、会话和素材，每轮固定所选智能体；修图工具不能调用付费生图。上传的 PNG、JPEG、WebP 原文件完整保存（每张最多 50MiB、6400 万像素，每轮最多 8 张，新上传总计 200MiB，不支持动画），模型预览和生图参考另行缩图。旧记录中已经压缩的参考图不能还原为原文件。

普通图片创作同样接受每张 50MiB、6400 万像素、新上传总计 200MiB，数量按当前模型限制。上传原文件随任务按账号归属逐字节归档，可从图像详情中的“参考原图”读回；原尺寸精修入口是修图 Agent。界面沿用 MB 标记，字节校验按 1024² 计算。

相机 JPG 中的 MPO 主图与附图不会被当作动画：原文件完整保留，使用第零幅高分辨率主图处理，并按 EXIF 校正工作副本方向、保留色彩配置。修图工作副本为全分辨率无损 PNG。生图参考与原图分开：本地 Qwen 2.1 的参考副本限制在 1024² 像素以内，防止上游跳过缩放时直接编码超大参考图；云端仍沿用 20MiB / 32MP 边界，超过时生成最长边 2048px 的独立缩图，保留透明通道。不提高输出规格或费用，动画 PNG/WebP 仍不支持。

`editing.py` 提供有界 Pillow 工具和 PhotoCraft 命令白名单；`photocraft.py` 由网关独立建立 stdio MCP 会话。`edit_skills.py` 定义修图技能、专业术语及工具接口。没有 PhotoCraft 时仍可使用 Python 尺寸与格式工具。

每次修改使用独立工作副本与 `edit_jobs` 账本；专业操作计划先落盘，随后逐步执行。PhotoCraft 每步保存 `.pcraft` 检查点，结果提供图片和原生工程下载，可通过 Agent 导出 PSD。PSD 导出会重开检查，但不承诺全部 Photoshop 特性兼容。当前网页上传入口限 PNG/JPEG/WebP，不接受 PSD/pcraft 上传。

桌面模式使用专用客户端、回环鉴权和跨进程锁，不接管用户的手工编辑实例。结果未知不重放写操作；网页“核对任务”检查已有文件与客户端状态，完整输出可以恢复，未完成任务保存检查点后结束。原图、结果、工程文件和事件流沿用服务端账号及会话归属校验。删除对话仅隐藏本人视图。

本目录包含项目自有的 Python 服务。完整安装与启动命令见 [部署说明](../docs/DEPLOYMENT.md)，项目功能见 [README](../README.md)。依赖固定在 `requirements-lock.txt`，应使用独立的 Python 3.12 虚拟环境。

## 服务与数据

- 入口端口7801，代理回环地址上的SwarmUI 7802；ComfyUI 8188由SwarmUI调度。
- 默认数据库为 `runtime/studio-accounts.sqlite3`，可使用 `--database` 指定独立实例；测试实例不得复用生产库。
- `server.py` 负责认证、代理、资源边界和任务核对，`store.py` 保存账号与任务账本。
- `local_queue.py` 提供本地GPU的FIFO队列及基于历史中位速率的等待估计；样本不足或超时显示未知。
- `agent.py` / `agent_store.py` 提供LangGraph工具循环、SSE事件、对话及素材归属。
- `agent_context.py` 管理增量会话摘要，`agent_skills.py` 包含人设、技能与工具定义。

## 账号边界

- `/studio-auth/` 提供登录、注册、退出、普通账号重置、任务隐藏与管理员概览。
- `/API/`、生成WebSocket、`/View`、`/Output`、`/studio-results`、`/studio-agent/` 必须认证。
- `/studio/` 下的网页、展示样张与模板是公共素材，禁止放入私人作品。
- 普通用户映射独立的 `nd_*` Swarm身份，管理员保留本机身份。Swarm必须安装NandouCommerce扩展，确保转发的普通用户不获得上游管理员权限。
- 管理员同时要求数据库角色、真实回环来源和本机Host，不能仅凭Host或转发头判断。
- 普通用户只凭邮箱重置密码是当前内部过渡规则，未验证邮箱所有权；管理员不允许此方式。退出与重置撤销该账号全部会话。
- 隐藏任务只更新可见性，原始作品和费用保留给管理员。活动或结果未知的任务不能隐藏。

## 生成与恢复

- 请求编号全局预占，付费提交前先落盘。响应丢失时标记结果未知，后台只查询原任务，不重发创建。
- 服务重启不重放已派发的生成请求；从未派发的本地请求可继续排队，已派发请求核对保存结果。
- 队列只暴露本人位置与估计，不暴露他人提示词、邮箱或图片。取消仅作用于本人指定任务。
- 默认每轮有10次常规模型调用，临近上限时优先完成交付。已有文件最多增加一次检查或导出工具轮和一次文字回复；无文件时只增加一次文字回复。收尾阶段不能追加生成或修图。图片上限4张，单账号1个活动轮次，服务端同时最多3轮。
- 两种 Agent 共享品牌、编辑排版、插画分镜、信息与界面、空间与图案技能。设计资料检索只将预设公开主题发送给芝加哥艺术博物馆，每轮至多两个不同主题，每个主题最多三条馆藏记录与一张公版作品缩略图。版式方法参考 [Open Design](https://github.com/nexu-io/open-design/tree/87a4f91c308170a8270458fc40fc66a86ed69aac/design-templates)，由现有模型根据用户要求执行。
- 主循环DeepSeek默认使用 `thinking.type=enabled`、`reasoning_effort=high`，工具调用参数完整收到后才执行；内部推理只在轮次内存中按协议回传，不落盘、不发给前端，关闭LangSmith tracing。
- 默认Flare / medium / 1K，质量禁止auto与max；智能比例不改变画质或分辨率。固定比例和张数上限在工具边界执行。
- 用户停止后不再执行后续Agent步骤，但已经提交的云任务可能继续完成并计费。

## 摘要、偏好与草稿

- 对话没有固定轮数上限。未归入摘要的公开事件超过40条或24000字符时，整理较早记录，保留至少最近12条公开记录与最近4轮完整对话。
- 摘要保存到 `agent_summaries`，原始事件不删除；摘要失败不推进游标，也不继续本轮生图。摘要仍可能遗漏细节，可在对话顶部查看。
- `/studio-agent/memory` 只读写当前账号的手动偏好，最多4000字符，空字符串清空。当前消息和固定规格优先，不自动从聊天抽取长期记忆。
- 前端的文字、参考图和待确认消息编号保存在浏览器IndexedDB，按账号、模式及Agent对话分区。清除浏览器站点数据会丢失草稿；不跨设备同步。

## 维护验证

本仓库按发布要求不包含测试和运维脚本。本地已有测试使用临时SQLite、本机模拟上游和临时图片，覆盖账号边界、幂等、队列、SSE、摘要失败与手动记忆隔离。修改时仍应补充必要的本地检查，并按部署说明进行真实浏览器与两个普通账号验收；模拟通过不能替代真实生图交付。

## 输入、输出与图片预算

单次输出默认 32K，应用上下文默认 256K；可配置至官方 384K 输出、1M 上下文，并检查输入与输出的总预算。图片按图像计量，预览去重并按需查看，避免把 Base64 作为文本。摘要分批执行，输出 length、工具 JSON 不完整、超时与超预算均有明确停止提示。配置范围和视觉细节见 [部署说明](../docs/DEPLOYMENT.md#agent-长上下文与视觉预算)。
